🎯 System Overview

The DWCRA (Development of Women and Children in Rural Areas) System is a comprehensive web-based platform designed to manage self-help groups, loans, and payments. The system supports three main user roles:

👥 Group Leaders

Manage groups and apply for loans on behalf of their members.

👤 Group Members

Make payments and track payment history for their group loans.

🔧 Administrators

Oversee the entire system, manage users, and approve loans.

🚀 Accessing the System

Step 1: Open your web browser (Chrome recommended)
Step 2: Navigate to the DWCRA system URL provided by your organization
Step 3: The system will display the login page

Language Selection (Optional)

  • The system supports multiple languages (English and Telugu)
  • Click on the language toggle button to switch between languages
  • Your language preference will be saved for future sessions

📝 New User Registration

Step 1: On the login page, click the "New User? Register Here" link
Step 2: Complete the registration form with all required fields

Required Registration Fields

Field Description Requirements
Unique ID Your assigned identification number Must be unique in the system
Full Name Complete name as per official documents Use proper capitalization
Email Address Valid email for notifications Format: example@domain.com
Bank Name Your bank branch name Must match other group members
Password Create a strong password Minimum 8 characters
Role Select your role Group Leader or Group Member
Step 3: Click the "Register" button (green button)
Step 4: Complete identity verification in your Profile section

🔐 User Login Process

Step 1: Enter your Unique ID (case-sensitive)
Step 2: Enter your Password (case-sensitive)
Step 3: Click "Secure Login" button (blue button)
Step 4: System redirects to your role-specific dashboard

Password Recovery

  • Click "Forgot Password?" link on login page
  • Enter your registered email address
  • Check email for password reset instructions
  • Follow the link to create a new password

👥 Group Leader Workflow

Dashboard Access

  • URL: /leader_dashboard
  • Welcome message: "Welcome, [Name] (Group Leader)"
  • Four main action buttons displayed

Step 1: Identity Verification (First Time)

1. Click "Profile" button (amber/yellow button)
2. Upload required documents:
  • Government ID
  • Address proof
  • Bank account details
3. Submit for administrator approval
4. Wait for approval notification

Step 2: Create Group

1. Click "Create Group" button (blue button)
2. Enter 6 member Unique IDs:
  • Member 1, Member 2, Member 3
  • Member 4, Member 5, Member 6
3. Ensure all members:
  • Are registered in the system
  • Have verified their identity
  • Belong to the same bank as the leader
4. Click "Create Group" to submit

Step 3: Apply for Loan

1. Click "Apply for Loan" button (green button)
2. Fill loan application:
  • Loan Amount
  • Purpose
  • Repayment Period
  • Supporting Documents
3. Click "Submit Application"
4. Status: "Pending Approval"

👤 Group Member Workflow

Dashboard Access

  • URL: /member_dashboard
  • Welcome message: "Welcome, [Name] (Group Member)"
  • Four main action buttons displayed

Step 1: Identity Verification (First Time)

1. Click "Profile" button (amber/yellow button)
2. Upload required documents
3. Submit for administrator approval
4. Wait for approval notification

Step 2: Make Payment

1. Click "Make Payment" button (green button)
2. Fill payment form:
  • Payment Amount
  • Payment Method
  • Transaction Reference
  • Additional Notes (optional)
3. Click "Submit Payment"
4. Payment recorded in system

Step 3: View Payment History

1. Click "Payment History" button (cyan/blue button)
2. View all payments:
  • Payment dates
  • Amounts paid
  • Payment status
  • Transaction references

🔧 Administrator Workflow

Dashboard Access

  • URL: /admin_dashboard
  • Full navigation menu available
  • System analytics displayed

Step 1: User Management

1. Click "Users" in navigation
2. Available actions:
  • Create User: Add new users
  • Edit User: Modify user information
  • Delete User: Remove users
  • Reset Password: Generate new passwords

Step 2: Identity Verification Management

1. Click "Identity Verifications"
2. Available actions:
  • Approve: Accept verification
  • Reject: Deny with reason
  • View Documents: Review uploaded files

Step 3: Loan Management

1. Click "Loans" in navigation
2. Available actions:
  • Approve Loan: Accept application
  • Reject Loan: Deny with reason
  • Edit Loan: Modify details
  • View Details: Full application

Step 4: Reports Generation

1. Click "Reports" in navigation
2. Report types:
  • User Activity Reports
  • Payment Reports
  • Loan Status Reports
  • Group Performance Reports
3. Select date range and click "Generate Report"

👤 Profile Management

3. Status: "Pending Approval"

🚪 Logout Process

Step 1: Click "Logout" button from dashboard
Step 2: System automatically logs out
Step 3: Redirected to login page
Step 4: Session securely terminated

Security Features

  • All session data cleared
  • No personal information remains in browser
  • Must log in again to access system

🔧 Troubleshooting Guide

Login Issues

Problem: "Invalid credentials" error

  1. Check Unique ID spelling
  2. Verify password (case-sensitive)
  3. Try password reset if forgotten

Problem: Account locked

  1. Contact administrator
  2. Verify identity if required
  3. Reset password if necessary

Registration Issues

Problem: "Unique ID already exists"

  1. Contact administrator
  2. Verify Unique ID assignment
  3. Use different email if needed

Payment Issues

Problem: Payment not processing

  1. Check internet connection
  2. Verify payment details
  3. Contact administrator
