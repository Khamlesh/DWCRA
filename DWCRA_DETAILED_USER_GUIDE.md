## System Access and Navigation

### Initial System Access
**Step 1: Browser Setup**
1. Open your web browser (Chrome recommended)
2. Navigate to the DWCRA system URL
3. Wait for the login page to load completely

**Step 2: Language Selection**
1. Locate the language toggle button (top-right corner)
2. Click to switch between English and Telugu
3. Language preference is automatically saved

**Step 3: System Overview**
- The login page displays the DWCRA logo
- Title: "DWCRA Portal - Login"
- Two main options: Login and Register

## New User Registration Process

### Step 1: Access Registration Form
1. On the login page, locate the link: **"New User? Register Here"**
2. Click the link to navigate to registration page
3. URL changes to: `/register`

### Step 2: Complete Registration Form
**Form Fields (All Required):**

1. **Unique ID Field**
   - Label: "Unique ID"
   - Enter your assigned identification number
   - Must be unique in the system

2. **Full Name Field**
   - Label: "Full Name"
   - Enter complete name as per official documents
   - Use proper capitalization

3. **Email Address Field**
   - Label: "Email Address"
   - Enter valid email format (example@domain.com)
   - Used for password recovery and notifications

4. **Bank Name Field**
   - Label: "Bank Name"
   - Enter your bank branch name
   - Must match other group members' bank

5. **Password Field**
   - Label: "Password"
   - Minimum 8 characters required
   - Use strong password with letters, numbers, symbols

6. **Role Selection**
   - Label: "Role"
   - Dropdown options:
     - "Select Role" (default)
     - "Group Leader"
     - "Group Member"
   - Choose appropriate role

### Step 3: Submit Registration
1. Review all entered information
2. Click the **"Register"** button (green button)
3. System validates all fields
4. Success message: "Registration successful! Please log in."
5. Click **"Already have an account? Login here"** to proceed

### Step 4: Post-Registration Requirements
1. **Identity Verification Required**
   - Must complete before joining groups
   - Upload documents in Profile section
   - Wait for administrator approval

## User Login and Authentication

### Step 1: Enter Login Credentials
1. On login page, locate the login form
2. **Unique ID Field**
   - Enter your registered Unique ID
   - Case-sensitive entry

3. **Password Field**
   - Enter your password
   - Case-sensitive entry
   - Password field is masked

### Step 2: Submit Login
1. Click **"Secure Login"** button (blue button)
2. System validates credentials
3. If successful: Redirected to role-specific dashboard
4. If failed: Error message "Invalid credentials"

### Step 3: Password Recovery Process
1. Click **"Forgot Password?"** link on login page
2. Enter your registered email address
3. Click submit button
4. Check email for reset link
5. Follow link to create new password

## Group Leader Complete Workflow

### Dashboard Access
**After successful login:**
- URL: `/leader_dashboard`
- Welcome message: "Welcome, [Name] (Group Leader)"
- Four main action buttons displayed

### Step 1: Identity Verification (First Time Users)
1. Click **"Profile"** button (amber/yellow button)
2. Navigate to identity verification section
3. Upload required documents:
   - Government ID
   - Address proof
   - Bank account details
4. Submit for administrator approval
5. Wait for approval notification

### Step 2: Create Group Process
1. Click **"Create Group"** button (blue button)
2. **Group Creation Form:**
   - Enter 6 member Unique IDs
   - Fields: Member 1, Member 2, Member 3, Member 4, Member 5, Member 6
   - All members must be registered and verified
   - All members must have same bank as leader

3. **Validation Requirements:**
   - All 6 members must exist in system
   - All members must have "member" role
   - All members must have verified identity
   - All members must belong to same bank

4. **Submit Group Creation:**
   - Click **"Create Group"** button
   - Success message: "Group created successfully!"
   - Redirected to leader dashboard

### Step 3: Apply for Loan
1. Click **"Apply for Loan"** button (green button)
2. **Loan Application Form:**
   - Loan Amount: Enter requested amount
   - Purpose: Describe loan purpose
   - Repayment Period: Select duration
   - Supporting Documents: Upload required files

3. **Submit Loan Application:**
   - Click **"Submit Application"** button
   - Application sent to administrator
   - Status: "Pending Approval"

### Step 4: Monitor Group and Loan Status
**Dashboard Information:**
- Group member list
- Loan application status
- Repayment progress
- Payment history

**Group Management:**
- View all group members
- Check member payment status
- Access group reports
- Monitor group activities

## Administrator Complete Workflow

**After successful login:**
- URL: `/admin_dashboard`

1. Click **"Users"** in navigation menu
2. **User Management Page:**

3. **User Actions:**
   - **Create User**: Click "Create New User" button

2. **Verification Dashboard:**

   - User details and documents

3. **Verification Actions:**
   - **Approve**: Click "Approve" button
   - **Reject**: Click "Reject" button with reason

2. **Group Management Page:**
   - View all active groups
   - Group composition details
   - Group status information

3. **Report Types:**

2. **Notifications Dashboard:**

   - Track notification delivery

3. **Send Notifications:**

## System Logout and Security

### Logout Process
1. **Initiate Logout:**
   - Click **"Logout"** button from dashboard
   - Or click **"Logout"** from navigation menu

2. **Logout Confirmation:**
   - System automatically logs out
   - Redirected to login page
   - Session securely terminated

3. **Session Security:**
   - All session data cleared
   - No personal information remains
   - Must log in again to access system

### Security Best Practices
1. **Password Security:**
   - Use strong passwords (8+ characters)
   - Include letters, numbers, symbols
   - Never share passwords
   - Change regularly

2. **Session Security:**
   - Always log out when finished
   - Don't share login credentials
   - Avoid public computers
   - Clear browser cache

3. **Data Protection:**
   - Keep information updated
   - Report suspicious activity
   - Don't share sensitive data
   - Follow security policies

## Troubleshooting Guide

### Login Issues
**Problem**: "Invalid credentials" error
**Steps to Resolve:**
1. Check Unique ID spelling
2. Verify password (case-sensitive)
3. Try password reset if forgotten

**Problem**: Account locked
**Steps to Resolve:**
1. Contact administrator
2. Verify identity if required
3. Reset password if necessary

### Registration Issues
**Problem**: "Unique ID already exists"
**Steps to Resolve:**
1. Contact administrator
2. Verify Unique ID assignment
3. Use different email if needed

**Problem**: Form not submitting
**Steps to Resolve:**
1. Check all required fields
2. Verify email format
3. Ensure password meets requirements

### Payment Issues
**Problem**: Payment not processing
**Steps to Resolve:**
1. Check internet connection
2. Verify payment details
3. Contact administrator

**Problem**: Payment history missing
**Steps to Resolve:**
1. Refresh page
2. Check date filters
3. Contact administrator

### System Access Issues
**Problem**: Cannot access features
**Steps to Resolve:**
1. Verify user role permissions
2. Complete identity verification
3. Contact administrator

**Problem**: Slow page loading
**Steps to Resolve:**
1. Check internet connection
2. Clear browser cache
3. Refresh page
