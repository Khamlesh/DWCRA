# DWCRA System - Quick Reference Guide
## Step-by-Step Instructions for All Users

---

## 🚀 Getting Started

### First Time Access
1. **Open Browser** → Navigate to DWCRA system URL
2. **Language Selection** → Click language toggle (top-right)
3. **New User?** → Click "New User? Register Here"
4. **Existing User?** → Proceed to login

---

## 📝 New User Registration

### Step 1: Access Registration
- Click **"New User? Register Here"** on login page
- URL changes to: `/register`

### Step 2: Fill Registration Form
| Field | Description | Requirements |
|-------|-------------|--------------|
| **Unique ID** | Your assigned ID number | Must be unique |
| **Full Name** | Complete name | As per official documents |
| **Email** | Email address | Valid format (example@domain.com) |
| **Bank Name** | Your bank branch | Must match group members |
| **Password** | Create password | Minimum 8 characters |
| **Role** | Select role | Group Leader or Group Member |

### Step 3: Submit & Verify
1. Click **"Register"** button (green)
2. Success message: "Registration successful!"
3. Click **"Already have an account? Login here"**
4. **Complete Identity Verification** in Profile section

---

## 🔐 User Login

### Step 1: Enter Credentials
| Field | Action |
|-------|--------|
| **Unique ID** | Enter your registered ID |
| **Password** | Enter your password |

### Step 2: Login
- Click **"Secure Login"** button (blue)
- System redirects to role-specific dashboard

### Step 3: Password Recovery
- Click **"Forgot Password?"** link
- Enter email address
- Check email for reset link
- Create new password

---

## 👥 Group Leader Workflow

### Dashboard Access
- URL: `/leader_dashboard`
- Welcome: "Welcome, [Name] (Group Leader)"
- 4 action buttons available

### Step 1: Identity Verification (First Time)
1. Click **"Profile"** button (amber)
2. Upload required documents:
   - Government ID
   - Address proof
   - Bank account details
3. Submit for administrator approval
4. Wait for approval notification

### Step 2: Create Group
1. Click **"Create Group"** button (blue)
2. Enter 6 member Unique IDs:
   - Member 1, Member 2, Member 3
   - Member 4, Member 5, Member 6
3. **Requirements:**
   - All members must be registered
   - All members must be verified
   - All members must have same bank
4. Click **"Create Group"** to submit

### Step 3: Apply for Loan
1. Click **"Apply for Loan"** button (green)
2. Fill loan application:
   - Loan Amount
   - Purpose
   - Repayment Period
   - Supporting Documents
3. Click **"Submit Application"**
4. Status: "Pending Approval"

### Step 4: Monitor Status
- View group members
- Track loan status
- Monitor repayment progress
- Access payment history

---

## 👤 Group Member Workflow

### Dashboard Access
- URL: `/member_dashboard`
- Welcome: "Welcome, [Name] (Group Member)"
- 4 action buttons available

### Step 1: Identity Verification (First Time)
1. Click **"Profile"** button (amber)
2. Upload required documents
3. Submit for administrator approval
4. Wait for approval notification

### Step 2: Make Payment
1. Click **"Make Payment"** button (green)
2. Fill payment form:
   - Payment Amount
   - Payment Method
   - Transaction Reference
   - Additional Notes (optional)
3. Click **"Submit Payment"**
4. Payment recorded in system

### Step 3: View Payment History
1. Click **"Payment History"** button (cyan)
2. View all payments:
   - Payment dates
   - Amounts paid
   - Payment status
   - Transaction references

### Step 4: Monitor Status
- Current payment status
- Next due date
- Outstanding amounts
- Payment reminders

## 🔧 Administrator Workflow

### Dashboard Access
- URL: `/admin_dashboard`
- Full navigation menu available
- System analytics displayed

### Step 1: User Management
1. Click **"Users"** in navigation
2. **Actions Available:**
   - **Create User**: Add new users
   - **Edit User**: Modify user information
   - **Delete User**: Remove users
   - **Reset Password**: Generate new passwords

### Step 2: Identity Verification Management
1. Click **"Identity Verifications"**
2. **Actions:**
   - **Approve**: Accept verification
   - **Reject**: Deny with reason
   - **View Documents**: Review uploaded files

### Step 3: Group Management
1. Click **"Groups"** in navigation
2. View all active groups
3. Monitor group composition
4. Generate group reports

### Step 4: Loan Management
1. Click **"Loans"** in navigation
2. **Actions:**
   - **Approve Loan**: Accept application
   - **Reject Loan**: Deny with reason
   - **Edit Loan**: Modify details
   - **View Details**: Full application

### Step 5: Reports Generation
1. Click **"Reports"** in navigation
2. **Report Types:**
   - User Activity Reports
   - Payment Reports
   - Loan Status Reports
   - Group Performance Reports
3. Select date range
4. Click **"Generate Report"**

### Step 6: Notifications
1. Click **"Notifications"** in navigation
2. Send system notifications
3. Target specific user groups
4. Track delivery status

### Step 7: System Settings
1. Click **"Settings"** in navigation
2. Configure system parameters
3. Manage preferences

### Step 8: Audit Logs
1. Click **"Audit Logs"** in navigation
2. Review system activity
3. Monitor user actions

## 🚪 Logout Process

### Step 1: Initiate Logout
- Click **"Logout"** button from dashboard
- Or click **"Logout"** from navigation menu

### Step 2: Confirmation
- System automatically logs out
- Redirected to login page
- Session securely terminated

### Step 3: Security
- All session data cleared
- No personal information remains
- Must log in again to access system

## 🔧 Troubleshooting

### Login Issues
| Problem | Solution |
|---------|----------|
| "Invalid credentials" | Check Unique ID and password |
| Account locked | Contact administrator |
| Password forgotten | Use "Forgot Password?" link |

### Registration Issues
| Problem | Solution |
|---------|----------|
| "Unique ID exists" | Contact administrator |
| Form not submitting | Check all required fields |
| Email format error | Use valid email format |

### Payment Issues
| Problem | Solution |
|---------|----------|
| Payment not processing | Check internet connection |
| Payment history missing | Refresh page or contact admin |
| Transaction failed | Verify payment details |

### System Access Issues
| Problem | Solution |
|---------|----------|
| Cannot access features | Verify role permissions |
| Page loading slowly | Check internet connection |
| Identity verification pending | Complete verification process |
